# Support

Hyperblaze is an early alpha project maintained by Ashutosh Kumar Singh.

## Questions and Usage Help

- Start with the README and `docs/GETTING_STARTED.md`.
- Open a GitHub issue for reproducible bugs or feature requests.
- Include `hyperblaze --version`, `hyperblaze doctor`, your platform, and a minimal `BUILD.hb` when asking for help.

## Security Reports

Do not open public issues for suspected vulnerabilities. Follow `SECURITY.md` and email ashutoshkumarsingh0x@gmail.com.

## Funding and Sustainability

See `funding.json` and `.github/FUNDING.yml` for funding channels and current work plans.
