# Security Policy

## Supported Versions

Hyperblaze is in early alpha. Security fixes are currently made on the default branch and included in the next tagged release.

| Version | Supported |
| ------- | --------- |
| `master` | Yes |
| `0.1.x` | Best effort |

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities. Email Ashutosh Kumar Singh at ashutoshkumarsingh0x@gmail.com with:

- A short description of the issue and impact.
- Steps to reproduce or a proof of concept.
- Affected platform, branch, commit, or release.
- Any suggested mitigation or patch, if available.

You should receive an initial response within 7 days. If the issue is accepted, the fix will be developed privately where appropriate and disclosed after a patched release or mitigation is available.

## Scope

Reports are especially useful for issues involving command execution, path traversal, build-file parsing, cache poisoning, dependency confusion, unsafe file watching behavior, or anything that could cause Hyperblaze to run unexpected code.

Good-faith security research is welcome. Please avoid privacy violations, data destruction, service disruption, and public disclosure before a fix is available.
